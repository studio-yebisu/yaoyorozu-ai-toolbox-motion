# 動く作例の制作記録

各ツール・ライブラリの特性に合わせて制作した42本の作例と、制作スタックを紹介する40秒の紹介動画を用意しています。

2026年10月13日制作。42項目に、それぞれ独立した動画、GIF、静止ポスター、制作コードを用意しました。配信用動画は960×600・30fps。40本が8秒、`/motion`は12秒、CodeVideoModelは約5.2秒です。公開ページでは表示中の動画だけを読み込み、音を消してループ再生します。拡大時は標準の再生・シーク・音声操作が使えます。

## エージェントとスキルを使った制作

Claude Opus 5.5とCodexを使用しています。Claude Codeで、`claude --print --model claude-opus-5-5`を実行しました。全3回の完了結果の`modelUsage`が`claude-opus-5-5`であることを確認。全31件の作例設計と、GSAP・Three.js・Remotion ReleaseNotesの原案を相談し、さらに選択したスキルの原文6件を入力しました。

OpusからWhaley・Howseenの実装、Charlieの実装断片、Emilを含む4件の規則と時間構成が返りました。CodexがCharlieの欠けたヘルパーを補完し、Emilを実装。他ライブラリの実装、実行時の修正、レンダリング、書き出し、ページ統合もCodexが担当しています。コードの役割は各ファイルのコメントと作例説明に記載しました。

作品ごとに使用したスキル・実行環境・制作コードを記録しています。

## 制作スキルと素材

スキルは制作ルールとして適用し、描画するライブラリやエンジンと区別しています。参照した原文とcommitは[skill-inputs.json](../data/skill-inputs.json)に記録。第三者のSKILL全文やライセンス未確認のテンプレートは再配布していません。

- **Remotion Skills**：Sequenceのローカルフレーム、マスク、spring、フレーム由来の値。
- **Emil**：triggerからの起点、transform/opacity、短い応答、閉形式のspringで割り込み、速度を保つretarget、軽減設定。
- **Charlie**：apple-launch-filmから、上部の黒いisland、別々の幅・高さのspring、連続する製品ショット、架空製品だけの事実表を適用。SONORAは架空のスピーカーです。
- **Whaley**：映像と音を同じJSON時間表へ。波形がtimelineからcoverへつながり、Pythonの自作SFXを同期。2-pass loudnormで調整。
- **Howseen**：seek(t)、共有要素、120BPM、円形floodの四隅のクリア、文字のマスク。架空アプリ・データと明記。
- **/motion**：pinnedのtemplate・style・作例をローカルで参照し、独自SCENEを専用render.mjsで実出力。公開するのは独自場面と再現用の準備スクリプトです。
- **iart**：索引からkinetic-typographyを選択。行マスク、80ms stagger、480ms reveal、ARIA、軽減設定、単独HTMLと時刻固定。
- **Anatomy**：実際のSVGキットを使用。部品単位の構成、四段階の陰影、奥行き順の描画、機構と数値の連動、キーボード操作、動きの軽減を実装。
- **Opus Video Prompts**：資料のコード制作方法を適用した独自Canvas作品。資料自体の実行という扱いではありません。
- **Rive**：公式の`rocket.riv`を素材として使用。再生・入力・時間の制御を制作コードに組み込み、WASM runtimeで描画しました。[素材の出典](../examples/runtime/assets/RIVE-ASSET.json)と[MIT全文](../examples/runtime/assets/RIVE-LICENSE.txt)を同梱。
- **フォント・音**：ローカルFontsourceのInter Tight・JetBrains Mono、OSフォント。配布するwoff2にはOFLを同梱。Whaleyの音はNumPyによる独自合成。

## Anatomyの機構図解

AnatomyのSVG描画キットを確認済みコミット`e6600ff`で取得し、Codexで架空の小さなプレスを独自制作しました。65個の立体部品を奥行き順に描き、押し型が8秒で24mm往復します。表示する移動量と隙間は同じ時刻モデルから算出。スライダー・左右キーで操作でき、ライト／ダークの単独HTMLを用意しました。

今回実行したのはSVGキットとそのフレーム取得です。WebGLとベータ版3Dモードの検証は含みません。

[再現手順](../examples/anatomy/README.md) · [描画・操作コード](../examples/anatomy/build.mjs) · [運動モデル](../examples/anatomy/model.mjs) · [ライト版](../examples/anatomy/index.html)

## CodeVideoModelのコード動画

CodeVideoModelの公式レンダラーを用い、MiniMax-H3（ref2va）への入力となるコード動画（960×544・24fps・124フレーム、約5.17秒）を制作。Three.jsでS字道路、配送ローバー、障害物を構築し、window.reconstruction.seek(t)によって時刻から車体位置や車輪の回転を一意に計算する設計としました。カメラ軌道データの出力にも対応し、シーンコード側で走行ラインや配色の調整が可能です。

[再現手順](../examples/code-video-model/README.md) · [ネイティブ出力](../assets/previews/code-video-model-native.mp4)

## 検証

ブラウザのコード作例はフォント準備後にseekし、2回の描画更新を待ってフレームを取得。ページ例外・外部ネットワークのないことを確認。Remotion・Motion Canvas・HyperFrames・Manim・FFmpegは各エンジンで実行しました。WebMの実エンコードと読み戻し、WASMの実変換結果、Playwrightの実取得画像も記録しています。

初期33本の寸法・尺・フレーム数・ファイルハッシュ・GIF形式を検査し、縮小フレームの変化も確認。場面ごとの静止画で文字の欠けや配置を確認し、ブラウザで代表動画の再生・拡大・停止とスマホの配置を確認しました。検証結果と使用版は各作例の記録に掲載しています。

機械可読の記録は[preview-production.json](../data/preview-production.json)、再実行の入口は[examples/README.md](../examples/README.md)です。

## グラフ・関係図の追加9作例

[紹介投稿](https://x.com/damkina7/status/2109637722117714002)にある10リポジトリを確認し、D3の重複を除く9件を追加しました。[用途と確認範囲](データと図解.md)を掲載しています。これらの9作例はCodexが制作・実装。追加分についてClaudeへ新たなモデル相談を実行した記録はありません。

全9本は独自の架空データ、ローカルnpm依存、既存フォントを使用。第三者の投稿動画・画像・画面は転載していません。各ライブラリの実APIを使用し、描画完了後の240フレームを取得して8秒動画へエンコードします。Mermaidは生成したSVGへ独自の演出を加え、Chart.js／ECharts／Nivo等では自走アニメーションを止めてデータを更新します。APIと使用版は作品ごとにmanifestへ記録しています。出力は音声なしです。

追加後は全42本のファイルハッシュ・GIF・フレーム変化・制作コードを再検査しています。追加9本については、任意順・放置後・新しいページで同時刻を描いた画像が一致すること、外部通信と実行エラーがないこと、実際のMP4が再生・シークできることを確認。[サイト検証](サイト検証.md)に実行範囲を記載しています。
