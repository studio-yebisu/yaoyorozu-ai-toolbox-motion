# 動きを指定し、フレームで直す

「高級感」「もっと派手に」といった指示を、色・材質・移動量・時間へ置き換えます。最初に見せ方を決め、重要なフレームを確認しながら仕上げる進め方です。

## 実験記事から見る制作の流れ

[Florence「Opus 5.5 Motion Lab: Make Claude Animate Like a Studio」](https://x.com/flxrnc/status/2105311836190978392)は、液体タイトル、イヤホンの製品映像、3Dマスコットの制作実験を公開しています。初稿だけでなく、映像と音を直した指示も掲載しています。

- **具体的に指定する**：目的、尺、サイズ、FPS、色、書体、場面の主役を決めます。動きの速度や弾み、要素間の遅れ、避けたい表現も伝えます。
- **同じ時刻を描き直す**：フレーム番号と時刻から状態を決め、途中の一枚も再出力できるようにします。
- **見て、絞って直す**：コンタクトシートで全体を確認し、気になる動きの前後を比較。フレーム番号と変更する値を指定して、修正後も同じ場所を確認します。
- **音とループを仕上げる**：記事はWeb Audioで合成した音も使い、書き出した音のタイミングや境界を測定しています。

映像の追加指示は、液体タイトル10回、具体的に指示した製品映像15回、マスコット4回と作者が報告しています。制作時間や修正回数は、作者自身の実験記録です。記事中の音を1フレーム遅らせる設計や音量の値も、その作品の設定として扱います。

## 実装するときの参照先

- [Remotion：useCurrentFrame()](https://www.remotion.dev/docs/use-current-frame) — フレーム番号を使って描画する仕組み。
- [MDN：Animation.currentTime](https://developer.mozilla.org/en-US/docs/Web/API/Animation/currentTime) — Web Animationsの時刻はミリ秒。秒で指定した時刻には1,000を掛けます。
- [MDN：FontFaceSet.ready](https://developer.mozilla.org/en-US/docs/Web/API/FontFaceSet/ready) — フォントと関連レイアウトの準備を待つPromise。
- [MDN：OfflineAudioContext](https://developer.mozilla.org/en-US/docs/Web/API/OfflineAudioContext) — 音声をバッファへレンダリングするAPI。

HTMLの時刻指定関数には共通の標準名がありません。記事の`renderAt(t)`、このガイドの`seek(t)`、各エンジンのAPIを、使うレンダラーに合わせて接続します。非同期の素材準備や描画がある場合は、その完了を待ってからフレームを取得します。

ループは全N枚のうち0〜N−1を出力します。最終フレームと先頭を同じ絵にする必要はなく、再生したときに動きが連続することを確認します。拍への同期は、拍nごとに`round(n × 60 / BPM × FPS)`でフレームを求めると、丸めた間隔を足し続ける誤差を避けられます。

数値の検査に加え、完成した動画を視聴して判断します。[ガイドの修正ブリーフ](https://studio-yebisu.github.io/yaoyorozu-ai-toolbox-motion/guide.html#motion-direction)から始められます。
