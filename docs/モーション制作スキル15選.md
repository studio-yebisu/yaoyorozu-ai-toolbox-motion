# 投稿15件から選ぶモーション制作スキル・ツール

[RoundtableSpaceの紹介投稿](https://x.com/RoundtableSpace/status/2109958757891346459)にある15リポジトリを、つくりたいものと役割で整理しました。2026年10月13日確認。新しく紹介する7件は、製品紹介、素材編集、絵柄のある解説映像、Remotionの演出、GSAPの実装、モーションの設計を支える資料です。

**既存の作例付きカタログ7件、新たな制作資料7件、UI/UX側へ整理する1件**に分けています。新7件はREADME・実際のスキル本文・ライセンスを確認した資料集です。インストールや制作実行はしておらず、[42本の独自作例](../projects.html)の本数には加えていません。

### 1. Product Launch Motion

同じ図形をUIやロゴへ変形させ、カーソル操作、スプリング、音楽の拍に合わせて見せる制作スキル。現行v2はHTMLの時刻制御とPlaywright、FFmpegを使う。

**必要な環境：** Node.js 20以上、Playwright、FFmpeg、Python 3とnumpy。作者はClaude CodeとOpus 5.5を推奨。

**導入：** README掲載のskills CLI。

```text
npx skills add AbubakrChan/product-launch-motion
```

**利用条件と確認点：** v1のGSAP・HyperFrames手順はlegacy。スキル内には作者固有のローカルパスもあるため、自分の制作環境へ読み替える。MITはスキル・文章が対象で、サンプル映像やそのフレームは再利用できない。音楽とモデル利用料は別に確認する。

### 4. HyperFrames Student Kit

無音や言い直しの整理から、ストーリー、字幕、HyperFramesとGSAPの演出までをつなぐ制作キット。motion-showreelは一つのモチーフを変形させ、音楽の拍で章を切り替える。

**必要な環境：** Node.js 22以上、Git、FFmpegとffprobe、ChromeまたはChromium。Codex／Claude Codeに対応するスキルを同梱。

**導入：** README掲載のプロジェクト導入。

```text
git clone https://github.com/nateherkai/hyperframes-student-kit.git
cd hyperframes-student-kit
npm ci
npm run setup
npm test
```

**利用条件と確認点：** ローカルの合成素材デモには有料生成APIが不要。ElevenLabsの文字起こし・音声、Kie.aiの画像・動画・音楽生成は任意で、各アカウント・キー・利用枠が必要。AISロゴなどのブランド素材はMITの再利用対象外。

### 5. motion-graphics（Barty-Bart）

話者動画と文字起こしに合わせるmotion-broll、製品の流れをワンカットで見せるexplainer-engaging、効果音を配置・計測するsound-effectsなどを用途別に選べる。

**必要な環境：** 機能によりNode.js、Python、PlaywrightとChromium、FFmpeg。B-rollは元動画と時刻付きの文字起こしを用意する。音の仕上げはPython 3.10以上と音声解析の依存が必要。

**導入：** README掲載のskills CLIで必要なスキルを選択。

```text
npx skills add Barty-Bart/motion-graphics
```

**利用条件と確認点：** B-rollの初期設定はbashを前提とする。時刻のない文字起こしにはローカルfaster-whisper等が別途必要。フォントはOFL、アイコンはISC、同梱SFXはCC0との記載。追加取得する曲・効果音は個別条件を確認する。今回は人物分離など全6スキルの実行はしていない。

[確認したREADME](https://github.com/Barty-Bart/motion-graphics/blob/3d83d987d658601d8a1269eb691622bdcd427335/README.md) · [スキル本文](https://github.com/Barty-Bart/motion-graphics/blob/3d83d987d658601d8a1269eb691622bdcd427335/skills/motion-broll/SKILL.md) · [MIT（コード）／フォント・アイコン・音は個別条件](https://github.com/Barty-Bart/motion-graphics/blob/3d83d987d658601d8a1269eb691622bdcd427335/LICENSE)（確認commit: `3d83d98`）

### 6. Animate

Canvasへ図形を描き、絵柄のキット、ストーリー、音を組み合わせる制作スキル。台本、見た目、絵コンテを確認してからアニメーションへ進み、複数の縦横比に配置を調整する。

**必要な環境：** Claude Code、Node.js 18以上、PlaywrightとChromium、FFmpeg。ナレーションの単語時刻にはPythonとfaster-whisper。

**導入：** README掲載のClaude Codeプラグイン導入。

```text
/plugin marketplace add cth9191/animate
/plugin install animate@animate
```

**利用条件と確認点：** ElevenLabsのナレーションは任意で接続と利用枠が必要。手元の録音も使える。WebGLの専用スタイルは上流でも未提供と明記されており、既存のCanvas作風と区別する。

[確認したREADME](https://github.com/cth9191/animate/blob/7e5eb56feb2dd573f890e1b7b34748af43d58263/README.md) · [スキル本文](https://github.com/cth9191/animate/blob/7e5eb56feb2dd573f890e1b7b34748af43d58263/plugins/animate/skills/animate/SKILL.md) · [MIT](https://github.com/cth9191/animate/blob/7e5eb56feb2dd573f890e1b7b34748af43d58263/LICENSE)（確認commit: `7e5eb56`）

### 8. Claude Remotion Skill

ReactとRemotionの制作に、スプリング、登場順、退場、レイヤー、テーマの共通化を加える第三者スキル。書き出したフレームを見て修正する工程を含む。

**必要な環境：** Node.js、React、RemotionとCLI、描画用ブラウザ。フレーム確認にはRemotionの静止画出力かFFmpegを使う。

**導入：** README掲載のプロジェクト単位のフォルダ配置。

READMEの手順でリポジトリを取得し、remotion-motion-graphics/を制作プロジェクトの.claude/skills/へ配置する。READMEのmkdir・cp例はbash系シェル向け。

**利用条件と確認点：** Remotion公式のAgent Skillsとは別の作者・別リポジトリ。MITはこのスキルに適用され、Remotion本体の企業利用などの条件は別途確認する。常時微動や粒子などは作者の作風で、すべての作品に必要な規則ではない。

[確認したREADME](https://github.com/haidrrrry/claude-remotion-skill/blob/1dcbe5e3fc6cf970bd10d3cc05f0a8a5d19d0383/README.md) · [スキル本文](https://github.com/haidrrrry/claude-remotion-skill/blob/1dcbe5e3fc6cf970bd10d3cc05f0a8a5d19d0383/remotion-motion-graphics/SKILL.md) · [MIT（スキル）／Remotion本体は別条件](https://github.com/haidrrrry/claude-remotion-skill/blob/1dcbe5e3fc6cf970bd10d3cc05f0a8a5d19d0383/LICENSE)（確認commit: `1dcbe5e`）

### 14. GSAP AI Skills

GreenSock公式のAPI・タイムライン・プラグイン・フレームワーク連携スキル集。開始位置、ラベル、並行する動き、後片付けを整理する実装の参照先。

**必要な環境：** skills形式を読めるエージェントと、JavaScript／GSAPを使う制作環境。Reactなどは選択した構成に応じて用意する。

**導入：** README掲載のskills CLI。

```text
npx skills add https://github.com/greensock/gsap-skills
```

**利用条件と確認点：** スキル集はMITだがGSAP本体はStandard License。スキル単体にはMP4書き出し機能がなく、動画化には時刻制御と別の書き出し手段を組み合わせる。

[確認したREADME](https://github.com/greensock/gsap-skills/blob/aed9cfd3277740755f6bfc1155c7aa645403b760/README.md) · [スキル本文](https://github.com/greensock/gsap-skills/blob/aed9cfd3277740755f6bfc1155c7aa645403b760/skills/gsap-core/SKILL.md) · [MIT（スキル）／GSAP本体は独自ライセンス](https://github.com/greensock/gsap-skills/blob/aed9cfd3277740755f6bfc1155c7aa645403b760/LICENSE)（確認commit: `aed9cfd`）

## UI/UXデザインとの分担

投稿10番の[199-biotechnologies/motion-dev-animations-skill](https://github.com/199-biotechnologies/motion-dev-animations-skill)は、UIアニメーションの実装を中心に扱うため、姉妹リポジトリ [Claude UI・UXデザインガイド](https://github.com/studio-yebisu/yaoyorozu-ai-toolbox-ui-ux) 側へ整理しました。画面の設計、操作、アクセシビリティなどのUI/UX資料はそちらへ集約します。

このモーション制作ガイドでは、映像の演出、時刻の制御、書き出し、音と動きの同期を扱います。LottieFilesのモーション原則やGSAPのタイムラインなど、両分野で使う資料はその役割を示して紹介します。

## 利用条件と確認範囲

- 新7件はスキル・コード部分にMITを確認。Product Launch Motionの作例映像、Student KitのAISブランド素材は、そのMITに含まれません。
- [GSAP本体のStandard License](https://gsap.com/community/standard-license/)と[Remotion本体の利用条件](https://www.remotion.dev/docs/license)は、スキルのライセンスとは別です。「スキルが無料」から、制作の全工程やすべての用途が無料とは判断できません。
- 有料の音声・画像・動画・音楽生成は任意の工程です。モデル利用、サービス接続、素材権利は制作内容に合わせて確認します。
- 今回の確認は、固定commitのREADME、LICENSE、下記データに列挙したスキル・参照ファイルまで。動作、生成品質、速度、全スキルの網羅的な確認は行っていません。
